# Azure Virtual Network (VNet)

- Izolacja i segmentacja zasobów w chmurze.
- Możliwość tworzenia podsieci, połączeń VPN.
- Kontrola ruchu przez NSG (Network Security Group).

## Przykład użycia

- Tworzenie VNet przez portal lub ARM/Bicep.
- Konfiguracja podsieci i reguł NSG.
- Brak kodu C#, konfiguracja graficzna/skryptowa.
