# Azure Cloud Shell

- Wbudowany terminal w portalu Azure.
- Dostępny Bash i PowerShell.
- Preinstalowane narzędzia: Azure CLI, Azure PowerShell, Git.
- Przechowywanie plików w Azure Files.

## Przykład użycia

- Uruchom polecenie w portalu: `az group list`
- Możliwość automatyzacji zadań administracyjnych.
- Brak kodu C#, obsługa przez terminal.
