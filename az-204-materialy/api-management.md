# Azure API Management

- Zarządzanie, zabezpieczanie i monitorowanie API.
- Tworzenie gateway dla API.
- Wsparcie dla limitów, autoryzacji, cache.

## Przykład użycia

- Import API przez OpenAPI/Swagger.
- Konfiguracja polityk (np. limitowanie, transformacje).
- Publikacja API do developer portal.

- Brak kodu C#, konfiguracja przez portal lub ARM/Bicep.
